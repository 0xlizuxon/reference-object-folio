# 材料与故障对照

下列粗糙度以 Three.js 标准物理材质的 0–1 范围表示。光源尺寸、环境对比度、尺度与展示距离会改变结果。

## 纸板、布面与贴纸

纸板要有正面、包边和切口。先按参考中可见的厚度建薄实体，再为切口赋略暗、纤维方向不同的材质。书布经纬沿装订方向铺设，跨书脊时检查纹理比例。纸面可从 metalness 0、roughness 0.75–0.95 试起。细纤维主要进入 bump 或 roughness，避免把明暗颗粒直接画成黑白噪点。纹理在远处闪动时先减幅并检查 mipmap。

贴纸至少要有印墨面、切边和背胶。覆膜只作用在印刷正面；背面用低反射、偏灰白的粗糙材质。面上亮斑应随视角变化。翻起的边缘需要足够细分，沿弯曲弧线更新位置与法线。卷起时看背胶和逐渐拉开的投影；放平时检查是否与承载面深度冲突。若使用不规则轮廓，正面、背胶与阴影深度材质都应使用同一裁切形状。

## 裸金属、喷漆和小五金

金属扣或钥匙圈用有截面的实体。对照参考区分扁带、圆丝与冲压件，给转角和端头真实曲率。裸金属从 metalness 1、roughness 0.18–0.38 试起；哑光喷漆的表层通常按非金属处理。把狭长亮面放在零件侧前方，旁边留一条暗区。转动物件时应看见明暗带绕过截面。整件看起来黑时，检查 scene.environment；全白时，检查曝光和环境是否缺少暗部。有清晰拉丝方向的参考才增加定向纹理。

## 透明设备壳和显示屏

分开建圆角壳、壳内暗框、屏幕表面及内侧电路板。透明壳内外表面要有可读的距离，内部件要与外壁留间隙。透射材质先用 opacity 1、metalness 0；从 transmission 0.8–1、roughness 0.08–0.25、ior 约 1.49 开始比较。thickness 按物件局部单位与壁厚调整，考虑网格缩放。优先测试单层壳与不透明内件，再添加透明叠层；实时透射对透明物体之间的互视有局限。若屏幕像贴在壳上，先把显示层退到边框之后，并让盖板接住独立反光。老式 LCD 可用暗色像素和低对比底色，避免过强自发光冲掉字形。

## 一个近景练习：透明壳 BB 机

从实物参考估算圆角、壳厚、屏幕凹深与按钮凸出量的相对比例。搭出壳体、内框、屏幕、按钮四组，灰模阶段先检查侧面轮廓。给壳体后方放一条深色内框，在镜头一侧安排宽亮面。转到侧上方时，应能同时看到移动的壳边高光、位于其后的深框和更深处的屏幕字。若三者像印在同一平面，先修深度关系。最后才加螺丝孔、细字与局部使用痕迹。练习可以换成用户自己的任何透明设备，无需附带既有作品或品牌素材。

## 接触、阴影和性能

在零件底部、嵌槽和被遮住的缝中保留接触阴影。悬浮时先查承载高度与 shadow bias；硬黑边先查阴影范围、光源表现与环境填充。把纹理细节集中在近景可见处，重复零件共享几何和材质。移动设备若需要降负载，先减少离屏透射和阴影分辨率，再检查同一视角是否仍能区分关键材质。

## 烟灰注塑壳：同光线下的 BB 机对照

保留清透壳作为左侧基线。左右共用相机姿态、曝光、环境贴图、主辅光设置与模型尺度。烟灰改动仅作用于外壳和其下的板件，LCD 盖板继续用独立的低粗糙度材质。

此例机身宽约 0.88 场景单位，壳材质的 thickness 为 0.044。以下为 Three.js r160 本场景的对照值，颜色使用十六进制 sRGB 输入：

| 参数 | 清透壳 | 烟灰壳 |
| --- | --- | --- |
| color | #e5e7e3 | #d7d8d6 |
| roughness / transmission | 0.105 / 0.96 | 0.255 / 0.89 |
| clearcoat / clearcoatRoughness | 0.65 / 0 | 0.14 / 0.32 |
| attenuationColor / attenuationDistance | 白 / 无限 | #929391 / 0.18 |

先观察壳边反光宽度，再调灰色吸收。换模型尺度时按比例估算 thickness 和 attenuationDistance。粗糙透射模拟了柔雾的外观，未模拟真实塑料内部颗粒的多次散射。屏幕盖板保持 roughness 0.085，避免 LCD 同时发糊。

在 PCB 本身画低对比走线，将少量电容、端子和芯片放在壳后真实深度上。对照中按键后面的浅色元件只剩低对比轮廓，细走线在常规浏览距离几乎不可辨。若目标是让人认出电路，可先增加少量较大焊盘的面积，或缩短板到壳的距离；改完全机透射后要重新检查侧壁反光。验收时同步转至侧上方：观察侧壁上缘的亮带、下方面板中残留的元件轮廓，以及 LCD 字是否依旧清晰。

## 清透厚壁与分层亮边

先画侧壁的实体截面。沿外轮廓依次放置外倒角、浅槽、盖板搭接肩，再沿空腔的内壁返回起点，闭合截面并检查朝外的法线。将截面扫过圆角外框。相邻斜面的法线方向不同，接到环境软箱反射的位置也不同。前盖和后盖分件，避免重叠的共面透明片。将螺套或内部暗件放到壳后真实深度，为转动时的视差和透射提供参照。

本地侧壁样例的机身宽 2.21 单位，侧壁中央约 0.081 单位厚，材质取 ior 1.49、roughness 0.055、thickness 0.115。这些值是试验起点。Three.js 的实时透射近似依赖已渲染场景；多个切面的反光可以形成分层亮边，不能据此断言存在多次真实折射。固定同一相机与曝光对照前后版本，再慢转检查亮带是否分开移动、透过侧壁的暗件是否错位、正面是否仍清楚。本例最终动态观感待视觉复核。

## 三种按结构建模的材料练习

**磨砂半透明手柄**。用握把的外轮廓和截面曲率塑形，握掌处加厚，肩部向扳机收拢。保留空腔，在摇杆下分别放暗色底座，中央放短板，两翼放较浅的配重。宽约 2.3 单位的样机用 transmission 0.87、roughness 0.285、ior 1.48、thickness 0.095 和轻暖色吸收作起点。单独建外置按键。对照正面与侧转，检查内件有无视差，磨砂是否只留下低对比轮廓。若轮廓像几个亮方块，先改内件形状、填充率与对比度。

**淡紫珠光外壳**。将浅拱盖面、边框、装配缝和屏幕分件。盖面用多圈轮廓构成连续曲面，计算平滑法线。此前样机用 metalness 0.31、roughness 0.265、clearcoat 0.92、clearcoatRoughness 0.16、iridescence 0.65，薄膜厚度范围 240–410 nm。环境要有宽灯面与暗区。转动时观察高光在面板中央向边缘连续移动。若只看到一块银白，先检查面板曲率与曝光，再试颜色。

**心形和星形宝石**。以外轮廓为腰棱，上方连接约 64% 和 36% 两圈收缩轮廓，间隔顶点改变高度，下方收尖形成亭部。每个三角切面独立法线；心形凹口和星尖必须保留。用低粗糙度、局部透射与亮暗相间的环境，少量底色决定色相。在此例中试用 roughness 0.055、ior 1.84、transmission 0.23。逐帧转动，看相邻切面是否依次亮起。中央贴死的白斑或永远同色的三角形都应重做。效果以实物参考复核。


### 透明盒的侧壁与盖沿

先用带内孔的挤出截面连接内壁、外壁与端面，分别控制壁厚与盒深。给盖沿和底沿各自的窄倒角，保留装配缝。用斜侧面判断前后沿是否分开，视角转回正面时检查印刷是否仍清楚。若整面发灰，只在窄倒角上试调粗糙度或反射强度，保留宽壁的通透感。使用相同环境和曝光比较，分别记录侧壁是否更易辨认、最亮的边是否接近照片。只有正面照片时，斜侧面用于检验结构的合理性，厚度仍属推定。
